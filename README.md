# Patterns-Java

A collection of Java pattern programs designed for beginners to practice
logic building, nested loops, and problem-solving skills.

## Patterns Included

- Solid Square
- Solid Rectangle
- Solid Diamond
- Solid Rhombus
- Solid Right Triangle
- Hollow Square
- Hollow Rectangle
- Hollow Diamond
- Hollow Right Triangle
- Butterfly Pattern
- Inverted Butterfly Pattern
- Double Triangle
- Pyramid Patterns
- Inverted Pyramid
- Inverted Right Triangle
- Number Patterns
- Alphabet Patterns

## Technologies Used

- Java
- IntelliJ IDEA

## What You'll Learn

- Nested loops
- Pattern logic
- Row and column manipulation
- Conditional statements
- Number and alphabet patterns
- Problem-solving and logical thinking

## Purpose

This repository is created for Java practice, logic building,
and interview preparation.

It is also useful for beginners who are learning loops and
want to strengthen their problem-solving skills.
