# Patterns-Java

A collection of Java pattern programs for beginners to improve logic building and loop concepts.

## Patterns Included
- Solid Square
- Solid Rectangle
- Solid Diamond
- Hollow Rectangle
- Hollow Diamond
- Hollow Right Triangle
- Butterfly Pattern
- Number Patterns
- Alphabet Patterns
- Pyramid Patterns
- Inverted Patterns

## Technologies Used
- Java
- IntelliJ IDEA

## Purpose
This repository is created for Java practice and interview preparation.
